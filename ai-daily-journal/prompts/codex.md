# AI日誌 BUILD PROMPT v1.0｜Codex向け

下の枠を右上のボタンでコピーし、新しいCodexの作業へ貼り付ける。

```text
【AI日誌 BUILD PROMPT v1.0｜Codex向け】

あなたの役割は、私のPC上に「AI日誌」を実装し、実際に稼働する状態まで完成させることです。

Codexでの実装にあたり、対象に最も近いAGENTS.mdと既存の自動化規則を先に確認してください。Codexのネイティブな自動化が使える場合は、それ自体を日次の実行主体として扱い、自動化の中から別の `codex exec` や同じ日次処理を再帰的に起動しないでください。ネイティブな自動化が使えない場合は、OS標準の安定した方法を選び、実現できない範囲を実装済みと報告しないでください。

毎朝7時の自動実行では、PCのローカルタイムゾーンを基準に前日分を1件だけ生成してください。手動実行では対象日を指定できるようにしてください。

## ゴール

その日にAIと行った会話・作業ログから、

- 何を考えたか
- 何を決めたか
- 何を作ったか
- 何が変わったか
- 次に何をするのか

を抽出し、1日1つのMarkdown形式の日誌として自動生成・保存してください。

単なる会話要約ではなく、**その日の意味を圧縮して残すこと**を目的とします。

## 最初にやること

実装を始める前に、このPCの環境を調査してください。

- OS
- Codex / Claude Codeの利用環境
- 取得可能なAI会話・作業ログ
- Obsidianの有無
- 保存可能なVault / ディレクトリ
- 既存の自動化環境
- 利用可能なスケジューラ

不明な点だけ私に確認してください。

確認後は、設計だけで止まらず、
**実装 → テスト → 修正 → 再テスト**
まで自律的に進めてください。

## 実装要件

AI日誌は、取得できる範囲でその日のログを横断して生成してください。

可能であれば、

- Codex
- Claude Code
- その他ローカルで取得可能なAI作業ログ

を個別に解析し、最後に統合してください。

各AIの出力はそのまま採用せず、重複を除去し、重要な出来事の取りこぼしがないか確認してください。

取得できないAIやログは「未取得」と明記し、0件、成功、確認済みとして補完しないでください。AI自身の最終報告と、実ファイルや外部状態を再確認した事実も区別してください。

## 日誌フォーマット

1日1ファイル、Markdown形式で保存してください。

例：

`YYYY-MM-DD_AI-Journal.md`

内容は最低限、

# AI Daily Journal

## 今日の主要イベント
## 考えたこと・気づき
## 決定したこと
## 作ったもの・進めたこと
## 変更・修正したこと
## 未解決・保留
## 次にやること

を含めてください。

会話全文を保存するのではなく、
**後から読んでその日の流れと判断が復元できる粒度**でまとめてください。

確認できた事実とAIによる考察を混ぜないでください。ログにない動機、成果、成功を推測で補わず、わからないことは「ログからは不明」と書いてください。

## 保存

Obsidianが存在する場合は、
指定されたVault内にAI日誌用フォルダを作成してください。

存在しない場合は、
ユーザーが指定するローカルディレクトリへ保存してください。

## 自動化

実装後、AI日誌が【毎日朝7時に】自動生成されるようにしてください。

実行時刻や方法は、このPCで最も安定する仕組みを選んでください。

ただし、

- 既存の自動化を壊さない
- 同じ日誌を重複生成しない
- PC停止中などで失敗した場合は次回補完できる
- 実行ログとエラーログを残す

構成にしてください。

日付単位の排他制御を行い、同じ対象日の処理を同時に2つ進めないでください。完成ファイルは一時ファイルで検証してから原子的に公開し、完成後に再読込して対象日、必須見出し、非空、保存先、重複がないことを監査してください。

## 安全要件

以下は厳守してください。

- APIキー、トークン、認証情報を日誌へ書かない
- 個人情報や機密情報を不用意に外部送信しない
- 既存ファイルを勝手に削除・上書きしない
- 変更前に必要なバックアップを作成する
- 危険な操作は実行前に確認する

元ログは読み取り専用で扱ってください。日誌生成のために外部APIやクラウドへログ本文を送る必要がある場合は、送信先、送信内容、保持条件を説明し、実行前に確認してください。

## 完了条件

「実装しました」で終了しないでください。

実際のログを使ってテスト用AI日誌を1件生成し、

1. ログ取得
2. 抽出
3. 統合
4. Markdown生成
5. 指定先への保存
6. 自動実行設定

まで正常に動作することを確認してください。

不具合があれば原因を特定し、
**修正 → 再テストを繰り返してください。**

すべてPASSした時点で、
構築した仕組み・保存場所・自動実行方法・変更したファイルを私に報告してください。

確認できなかった項目がある場合は、確認できたこと、確認できなかったこと、その理由、残るリスクを分けて報告してください。

以上。
```
